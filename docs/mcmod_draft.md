# MCMOD 正文草稿

Civillis 是一个基于 Fabric 的生存向模组，核心理念是让玩家的建筑活动自然地压制怪物刷新。不需要学习新的机制，不需要额外配置——放置营火、床、工作台这些日常方块，周围的怪物刷新就会被逐渐压制。聚落规模越大，安全范围越广。

## 文明评分

模组会实时检测每个潜在刷怪点周围 240×240×48 格（15×15×3 体素区块）范围内的方块，计算出一个文明分数。营火、床、熔炉、工作台、信标等具有"人类活动痕迹"的方块都会贡献分数。

分数越高，怪物刷新压制越强。一座成熟的城镇可以将刷怪边界推至约 90 格外；即使是一间小木屋，也能提供一定程度的保护。

## 文明衰退与恢复

玩家离开后，文明分数会随时间缓慢衰退。但大型聚落即使经历完整的衰退周期，仍然保留约 40 格的安全范围——不会彻底归零。

重新回到衰退区域后，文明分数会逐渐恢复，停留时间越长恢复越多。

## 怪物头颅

放置怪物头颅（骷髅头、僵尸头等）可以在文明区域内重新开放对应种类的怪物刷新。头颅同时会从整个维度吸引对应种类的怪物向自身聚集，适合用于建造刷怪塔或定向引导怪物。

不同种类的头颅吸引不同种类的怪物，可以混合放置来控制刷怪比例。Civillis 不会破坏现有的刷怪塔设计，只会让它更高效。

## 文明探测器

模组提供一个可合成的手持道具——文明探测器，合成方式为指南针被绿宝石环绕。

右键使用后，探测器会发出一次声纳脉冲。效果分为两个阶段：

蓄力阶段会在玩家位置生成一道垂直粒子柱，粒子颜色反映当前所处区域的类型：白色粒子代表高文明区域，蓝色灵魂火焰代表低文明或荒野区域，橙色火焰代表怪物头颅的图腾区域。

随后进入激波阶段，两道同心粒子环从玩家位置向外扩散。粒子颜色会根据经过的世界坐标实时切换，直观地呈现周围不同区域的分布。

声纳经过文明边界时，会在边界位置升起半透明的发光墙壁：金色墙壁标记文明边界，紫水晶色墙壁标记怪物头颅图腾区的边界。墙壁会呼吸闪烁，随后缓慢消散。

## 配置

安装 Mod Menu 和 Cloth Config 后，可以在游戏内暂停菜单直接调整模组参数，包括刷新压制强度、检测范围、衰退速度、恢复速度、衰退下限、巡逻范围等。声纳视觉效果也可以在设置中单独开关。

不安装这两个前置模组时，模组使用默认配置正常运行。

## 安装

- Minecraft 1.21.1～1.21.11
- Fabric Loader ≥ 0.18.2
- Fabric API
- 可选：Mod Menu + Cloth Config（游戏内设置界面）
